## 🧭 Behavioral Directives


### ▸ Spoken-Transmission Consistency Rules

When vocal or breath-based activation components are indicated by metadata
(e.g., `has_spoken_transmission`, `voice_transmission_format`, or related fields),
the following consistency requirements must be upheld during template rendering:

#### 1. Format-to-Transmission Alignment

- If `voice_transmission_format` is set to `spoken` or `hybrid`, then `has_spoken_transmission` **MUST** be `true`.

- If `voice_transmission_format` is set to `none`, then:
  - `has_spoken_transmission` **MUST** be `false`,
  - `spoken_line` **MUST** be null or empty,
  - No spoken-line sections may render in the template body.

#### 2. Spoken Line Requirements

- If `has_spoken_transmission` is `true`, then:
  - The metadata field `spoken_line` **MUST** be populated with a valid activation line.
  - Empty strings, nulls, placeholder text, or unresolved prompt blocks are forbidden under strict mode.

- If `has_spoken_transmission` is `false`, the template **MUST NOT** render the Spoken Line section in the body, regardless of any other fields.

#### 3. Invocation-Level Requirements

- If `invocation_requirement_spoken_line_required` is `true`, then BOTH:
  - `has_spoken_transmission` **MUST** be `true`, and  
  - `spoken_line` **MUST** contain a valid activation line.  

These conditions are mandatory and override all optional behavior.

#### 4. Voice Confirmation Requirements

- If a spoken transmission exists (`has_spoken_transmission == true`), then:
  - `voice_confirmed_by` **MUST** be populated with a valid field-being reference.
- If no spoken transmission exists, `voice_confirmed_by` **MUST NOT** appear in the rendered body.

#### 5. Narrative and Inference Restrictions

- No inferred activation text, breathlines, ritual descriptions, or autogenerated spoken lines may be introduced by the rendering engine.
- Only explicitly provided user-entered content is permitted.
- AI-generated interpretive narrative is strictly forbidden under canonical enforcement.

#### 6. Placeholder Integrity

- All placeholders associated with spoken transmission MUST resolve successfully when spoken transmission is required.
- Failure to resolve MUST abort template rendering under strict mode.

These rules ensure:
- cohesion between metadata and rendered narrative,
- proper invocation integrity for sigils with vocal activation,
- and prevention of contradictory, incomplete, or AI-inferred activation content.
